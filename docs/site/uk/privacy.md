# Приватність

Редакція від 16.11.2026. Сторінка описує, які дані бачить автор проєкту Obscura Text Writer, коли ви користуєтеся застосунком, цим сайтом, записуєтеся в список очікування платної версії або пишете нам. Питання й запити щодо приватності надсилайте на [privacy@obscurawriter.com](mailto:privacy@obscurawriter.com).

## Застосунок

- Застосунок працює на вашому комп’ютері. Твори, налаштування, історія версій і журнали зберігаються в локальному каталозі даних (типово `%USERPROFILE%\Obscura`). Автор проєкту їх не отримує й не бачить.
- Ключі провайдерів зберігаються у сховищі облікових даних Windows або у вашому файлі `.env`. Вони нікуди не надсилаються, крім провайдера, якому належить ключ.
- У застосунку немає телеметрії, аналітики, реклами й автоматичної перевірки оновлень. Застосунок не надсилає авторові проєкту звітів про помилки.
- Текст покидає комп’ютер лише тоді, коли ви запускаєте етап із хмарною моделлю. Тоді частину твору, потрібну для етапу, отримує вибраний вами провайдер (наприклад, OpenRouter чи Venice) і обробляє її за власними умовами й політикою приватності. Локальна модель тексту нікуди не надсилає. Докладніше — у розділі [Моделі й бюджет](models.md).
- Якщо ви встановили застосунок із Microsoft Store, дані про встановлення й покупку обробляє Microsoft за своєю політикою приватності. Автор проєкту отримує від Microsoft лише узагальнену статистику магазину, без ваших творів.

## Цей сайт

- На сайті немає облікових записів, cookies, аналітики й рекламних пікселів. Мовні налаштування запам’ятовуються лише у вашому браузері (`localStorage`), якщо ви самі перемкнули мову.
- Єдина форма — список очікування на сторінці [Платна версія](paid.md). Там працює Cloudflare Turnstile: він перевіряє, що форму заповнює людина, і для цього обробляє технічні дані браузера за політикою приватності Cloudflare. Що відбувається з адресою, описано нижче, у розділі [Список очікування](#список-очікування).
- Сайт розміщено на GitHub Pages. GitHub може записувати технічні дані запитів, зокрема IP-адресу, для безпеки та роботи сервісу, за своєю політикою приватності. Доменні імена обслуговує Cloudflare (DNS).
- Посилання на GitHub, провайдерів моделей та інші сайти ведуть на сервіси з власними правилами приватності.

## Листи

- Коли ви пишете на [privacy@obscurawriter.com](mailto:privacy@obscurawriter.com) або [report@obscurawriter.com](mailto:report@obscurawriter.com), автор проєкту отримує вашу адресу, текст листа й вкладення. Листи пересилаються через Cloudflare Email Routing до поштової скриньки автора.
- Ці дані використовуються лише для відповіді та розгляду звернення й не передаються третім особам, крім випадків, коли цього вимагає закон. Листи зберігаються, поки потрібні для розгляду, або до вашого запиту на видалення.
- Не надсилайте ключів провайдерів. Фрагменти творів додавайте лише тоді, коли без них звернення не розглянути.

## Список очікування

- Коли ви записуєтеся на сторінці [Платна версія](paid.md), зберігаються ваша адреса електронної пошти, мова сторінки, дата запису й дата редакції цієї сторінки, з якою ви погодилися. IP-адреса передається лише Cloudflare Turnstile для перевірки й не зберігається.
- Мета — один лист про вихід платної версії. Підстава — ваша згода, яку ви даєте позначкою у формі.
- Записи зберігаються в базі Cloudflare D1 у юрисдикції ЄС. Cloudflare обробляє їх за дорученням автора проєкту.
- Адресу зберігають до листа про вихід платної версії, але не довше 24 місяців від запису: старіші записи видаляються автоматично щодня. Після листа список видаляють повністю.
- Підтвердження адреси листом немає. Якщо вашу адресу записав хтось інший або ви передумали, напишіть на [privacy@obscurawriter.com](mailto:privacy@obscurawriter.com), і запис видалять.
