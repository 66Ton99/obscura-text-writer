# Власний домен сайту інструкцій, приватність, скарги, SEO і вибір мови (R-36)

Дата: 15.11.2026. Статус: погоджено власником у чаті 15.11.2026; реалізовано одним PR.

## Контекст

Власник придбав `obscurawriter.com` у Cloudflare Registrar ($11.17/рік, автопродовження) і хоче використовувати сайт як цільову сторінку таргетованої реклами, а також як джерело адрес для Microsoft Store: політика приватності, адреса скарг `--report-url` (PACKAGING-001). DNS-записи A/AAAA на GitHub Pages і CNAME `www` (DNS only) та власний домен у налаштуваннях Pages власник уже задав; сайт за доменом відкривається.

## Рішення власника

- Залишитися на GitHub Pages. Cloudflare Pages на цьому етапі нічого не додає статичному сайту, а перехід змінив би спосіб публікації (`site.yml`, DOCS-SITE-S04/S05).
- Пошта: privacy@obscurawriter.com для приватності й report@obscurawriter.com для скарг, переадресація Cloudflare Email Routing на скриньку власника (налаштовує власник).
- Обсяг цього PR: заміна адрес, сторінки `privacy` і `report`, SEO-база (canonical, hreflang, Open Graph, `robots.txt`, `sitemap.xml`, `404.html`), автоматичний вибір мови: українську сторінку бачать лише ті, у кого в браузері є українська.
- Рекламні пікселі й банер згоди на cookies — окремо, R-37 / #176.

## Дизайн

- `site.json`: `base_url` (`https://obscurawriter.com/`) і `description` для `uk`/`en`. Обидва поля необов’язкові, тож тестові й локальні збірки без адреси не змінюються, крім підключення `site.js`.
- `build_site.py`: `head_meta` (description, canonical, alternates `uk`/`en`/`x-default` → англійська, Open Graph), `robots.txt`, `sitemap.xml` без дат (детермінованість), двомовна `404.html` з абсолютними посиланнями й `noindex`. Неправильний `base_url` зупиняє збірку.
- `site.js` (класичний скрипт у `<head>`, щоб перехід відбувся до відмальовування): на українській сторінці перехід на `data-alt` з рядком запиту, але без якоря, якщо збережено `en` або якщо вибору немає, у мовах браузера немає `uk` і це не робот; перемикач мови з `data-lang` зберігає вибір у `localStorage`. Збережений вибір має перевагу над браузером.
- Сторінки `privacy` і `report` uk/en; посилання з `legal`; контакти в Умовах використання (замість заповнювача); `docs/packaging.md` — `--report-url https://obscurawriter.com/report.html`.

## Відхилені варіанти

- Мовний вибір на окремій кореневій сторінці: змінив би структуру адрес (українська в корені) і всі посилання з README.
- Перенаправлення за `Accept-Language` на сервері: GitHub Pages його не підтримує.
- Ставитися до `ru` як до мовної ознаки української аудиторії: власник просив орієнтуватися саме на українську.

## Ризики й обмеження

- Пошуковий робот без ознаки робота в user agent піде на англійську сторінку; hreflang і canonical українських сторінок лишаються коректними.
- Open Graph без зображення (немає погодженого знімка для прев’ю).
- Сторінки приватності й скарг — текст автора проєкту, а не юридичний висновок; Умови використання досі чернетка.
