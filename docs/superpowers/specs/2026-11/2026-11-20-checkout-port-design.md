## Для власника

### Мета

Obscura з робочої копії і застосунок зі Store працюють одночасно без ручної правки `scripts/start.ps1`.

### Що зміниться для тебе

- Робоча копія типово відкривається на `http://127.0.0.1:8760`: `start.ps1`, `storygen`, налаштування застосунку.
- Міст MCP робочої копії без аргументів звертається до 8760.
- Застосунок зі Store не змінюється: бажаний порт 8765, за зайнятого — вільний, адреса в `server.json`.
- Локальну правку `start.ps1` можна прибрати: тека стане чистою.
- Запуски з явним `-Port`/`--port` і записи MCP з `--url` працюють як раніше.

### На чому стоїть рішення

- `desktop.PREFERRED_PORT = 8765` з пошуком вільного порту; `server.py`, `AppSettings`, `start.ps1` і `launch.DEFAULT_URL` мали жорсткий 8765 `[проба]`.
- Власник вибрав окремий порт замість автоматичного вибору порту для робочої копії `[вимога власника]`.
- `settings.port` використовується лише для запуску uvicorn, відкриття браузера й адреси, яку кнопки підключення Codex/Claude записують у конфігурацію; перевірки Origin/Host від нього не залежать `[проба]`.

### Ключові рішення

1. **8760** — порт, яким власник уже користується; не збігається з 8765.
2. Відкинуто: автоматичний вибір порту й запис `server.json` для робочої копії — більша зміна (M) з іншою логікою мосту MCP.

### Що стане гірше

- Порт робочої копії лишається фіксованим: дві робочі копії одночасно, як і раніше, потребують `-Port`.
- Запис MCP робочої копії без `--url` після оновлення звертається до 8760; робоча копія, запущена на 8765 явно, потребує `--url`.
