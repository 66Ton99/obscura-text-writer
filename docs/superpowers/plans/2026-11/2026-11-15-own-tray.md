# Власний значок у треї — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Замінити `pystray` власним кодом трея на `ctypes` і не пускати у збірку бібліотеки родини GPL.

**Architecture:** Новий модуль `storygen/win_tray.py` поділено на дві частини. Тонка обгортка `Win32Api` над `user32`/`shell32`/`kernel32` — єдине місце з `ctypes`. Клас `NotifyIcon` містить логіку віконної процедури й тестується з підміненим API. `desktop_tray.run_tray` зберігає підпис і будує `NotifyIcon` замість `pystray.Icon`. Охоронець `packaging.copyleft_distributions` зупиняє `third_party_notices`, а отже й збирання.

**Tech Stack:** Python 3.12, `ctypes` (Windows), Pillow (малюнок значка), pytest.

**Spec:** `docs/superpowers/specs/2026-11/2026-11-15-own-tray-design.md` (затверджено, PR #185).

## Global Constraints

- Нових залежностей немає. `pystray` зникає з `pyproject.toml`, аргументів PyInstaller і hooks. Pillow лишається.
- Поведінка значка як у `pystray`:
  - лівий клік (`NIN_SELECT`) і Enter (`NIN_KEYSELECT`) → типова дія, перший пункт `menu_items`;
  - `WM_CONTEXTMENU` → меню;
  - `TaskbarCreated` → значок знову;
  - підказка «Obscura».
- Події значка приходять повідомленням `CALLBACK = WM_APP + 1` (`0x8001`). Код події лежить у `LOWORD(lParam)`, координати версії 4 — у `wParam` (`x` = молодші 16 біт зі знаком, `y` = старші 16 біт зі знаком).
- `TrayUnavailable` дає невдача кожного з кроків: `RegisterClassW` (окрім помилки 1410 «клас уже є»), `CreateWindowExW`, значок, `NIM_ADD` чи `NIM_SETVERSION` під час запуску, а також `os.name != 'nt'`. Перед відмовою прибирається все створене.
- `HICON` створюється один раз і звільняється `DestroyIcon` після циклу й за невдачі. `NIM_DELETE` виконується в `finally`.
- Приховане вікно — звичайне невидиме вікно верхнього рівня, не `HWND_MESSAGE`, бо таке не отримує `TaskbarCreated`.
- Автотести MUST NOT показувати справжній значок у треї. Справжній API в тестах лише створює й знищує `HICON`.
- Документація українською; OpenSpec-маркери англійською. Кожен Scenario у traceability; `check_docs.py` проходить. Сайт uk/en парою з `check_site.py --rehash install`.
- Коміти закінчуються `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` і містять «Refs #119» та примітку про користувацьку документацію.

## Review Focus

1. **Правий клік, поки меню вже відкрите** (модальний цикл `TrackPopupMenuEx`). Очікувано: одне меню, без вкладених; повторний `WM_CONTEXTMENU` під час показу ігнорується.
2. **«Вийти», поки `stop()` чекає зупинки сервера (до 5 с).** Очікувано: `stop()` викликається рівно один раз, `close()` після нього не падає, цикл завершується.
3. **`close()` до старту циклу, після його кінця чи двічі** (`desktop._run` у `finally` викликає `stop`). Очікувано: без винятку й без повідомлення на знищене вікно.
4. **Виняток у дії меню** (не відкрився браузер чи Провідник). Очікувано: запис у журнал, значок і цикл працюють далі.
5. **Значок у позиції з від'ємними координатами** (монітор ліворуч від основного). Очікувано: меню з'являється біля значка, бо координати розбираються зі знаком.

  - `register_class(name: str, procedure: Callable[[int, int, int, int], int | None]) -> None` — `None` від процедури означає `DefWindowProcW`;
  - `unregister_class(name)`;
  - `create_window(class_name: str) -> int` і `destroy_window(hwnd)`;
  - `register_message(name: str) -> int`;
  - `small_icon_size() -> int`;
  - `icon_from_png(data: bytes, size: int) -> int` і `destroy_icon(hicon)`;
  - `add_icon(hwnd, hicon, tip: str) -> bool` (NIM_ADD з `uCallbackMessage=CALLBACK`, `uID=1`), `set_version(hwnd) -> bool`, `delete_icon(hwnd) -> None`;
  - `popup_menu(hwnd, labels: list[str], default: int, x: int, y: int) -> int` — вибраний id від 1 або 0; усередині `SetForegroundWindow`, `TrackPopupMenuEx(TPM_RETURNCMD|TPM_NONOTIFY|TPM_RIGHTBUTTON)`, `PostMessageW(WM_NULL)`, `DestroyMenu`;
  - `post(hwnd, message) -> None`;
  - `run_loop() -> None` (`GetMessageW` до `WM_QUIT`) і `post_quit()`.
  Будь-яка невдача `ctypes`-виклику, крім `add_icon`/`set_version`, які повертають `False`, кидає `TrayUnavailable`.
- `class NotifyIcon(api, title: str, icon_png: Callable[[int], bytes], items: list[tuple[str, Callable[[], None]]])`:
  - `run() -> None` блокує до виходу;
  - `close() -> None` безпечний з будь-якого потоку, до старту, після кінця й повторно;
  - `handle(hwnd, message, wparam, lparam) -> int | None` — логіка віконної процедури.
